## 🚀 Featured Projects

### 🎬 CineRAG — Agentic Movie Recommender
Self-evaluating 4-stage RAG pipeline: **Plan → Retrieve → Check → Generate**. Query gets decomposed, ChromaDB semantic search + MongoDB filters + reranker pull context, and an LLM scores it 0–10 — retrying up to 3× below threshold. GPT-4o-mini primary with a Groq Llama 3.3 70B fallback, local embeddings, zero API cost on retrieval.
**Result: 88–92% retrieval accuracy** · `LangGraph` `ChromaDB` `MongoDB` `OpenAI` `Groq` `Streamlit`

### 🤖 Multi-Modal AI Agent
Upload a receipt, whiteboard, or product photo, ask anything, and get back structured JSON shaped to that exact image and question — no fixed schema. Runs on Llama 4 Scout via Groq at 460+ tokens/sec.
`Llama 4 Scout` `Groq API` `Multimodal AI` `Streamlit`

### 📊 AI-Powered Data Analyst
Four specialized agents turn plain-English questions into analysis: one inspects schema and data quality, one writes pandas/matplotlib code, one reviews and fixes bugs, one explains the result in plain English. Groq Llama 3.3 70B with an Anthropic Claude Haiku fallback for zero downtime on rate limits.
`Groq` `Anthropic` `Pandas` `Matplotlib` `Streamlit`

### 📄 DocMind — Document Intelligence
Five-agent LangGraph pipeline for any PDF: Parser → Orchestrator → QA (RAG + reranking) → Summarizer (map-reduce) → Comparison (cross-document diffs) → Verifier, which scores confidence 0–100% and flags anything under 75%. Every answer carries a page-level citation.
`LangGraph` `ChromaDB` `PyMuPDF` `Groq` `FastAPI` `Streamlit`
